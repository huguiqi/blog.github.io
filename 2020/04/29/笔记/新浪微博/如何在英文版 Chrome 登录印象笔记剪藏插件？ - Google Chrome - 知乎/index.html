如何在英文版 Chrome 登录印象笔记剪藏插件？

切换电脑和浏览器语言为中文可以看到印象笔记切换入口。英文版Chrome印象笔记剪藏只有Evernote国际版帐号登录入口。如何在保持系统和浏览器语言是英文时，也可以切换登录印象笔记帐号？

说个直接在Chrome里的方法，适用于 6.2.3 (2f37fcd/1.1.0.654)1、鼠标右键点击扩展按钮，然后左键打开“选项”

2、鼠标右键页面空白位置，然后左键打开“审查元素”

3、在左下方的元素列表中层层展开，直到看见“developerContainer”

4、双击“display: none”，把它删掉

5、删完回车，关闭下方调试面板，然后在页面中向下滚动一下屏幕，就会出现开发者选项
%!(EXTRA markdown.ResourceType=, string=, string=)

6、将模拟简体中文选上，然后点击扩展按钮正常登录印象笔记吧！

需要把Chrome的语言设置更改为“简体中文”，在打开剪藏（Web Clipper）的时候会在登录界面的下方出现账户的切换选项，选择“我是印象笔记用户”即可。

写在前面：

(1). 本文后面修改的文件路径可能会随应用版本的不同而不同，在ubuntu系统下，chrome的插件是放在~/.config/google-chrome/Default/Extensions目录下；

(2). pioclpoplcdbaefihamjohnefbikjilc目录对应于Evernote Web Clipper,中文叫印象笔记–剪藏；

(3). iooicodkiihhpojmmeghjclgihfjdjhj目录对应于Evernote Clealy,中文名叫印象笔记–悦读；

(4). http://app.yinxiang.com是我们说的印象笔记，它与http://evernote.com(国际版)是不共用数据库的(不知道为什么这样弄，本人还特意花了30大洋来将国际版的数据迁移到中文印象笔记)，但它们是共用chrome插件，这个给用户带来很大的不便。
