修改 Mac 版 Safari、Chrome、FireFox、Opera 的 User-Agent 用户代理字符串

2011年07月17日 BY EYON IN 技巧&教程 / 1 条评论

对于浏览器工作原理不是太了解的同学可能不太明白，咦～为什么我在手机上访问 Google，就会直接给我跳到移动版呢？同样我在 iPhone 上访问果迷网为什么和在电脑上访问果迷网的界面不一样呢？其实，这一功能的实现就得归功于浏览器的 User-Agent，也就是浏览器的用户代理字符串。

简单的说，User-Agent 就是一个描述用户所使用的浏览器身份的一个标识，每当你访问一个网页的时候，浏览器会将这一串标识一起发送给目标网页，告诉目标网页你所使用的浏览器身份，包括浏览器种类、版本、操作系统等等信息。而网页服务器端也可以根据浏览器发来的身份信息，来判定你使用的浏览器，从而返回不同的网友。

这就是你使用手机访问 Google 会自动跳转到移动版本，使用 iPhone/Android/Opera-Mini 访问果迷网会自动显示一个专门为移动设备优化的网页的原因。

其实在电脑上，浏览器的 User-Agent 都是可以伪装的，比如你可以将电脑上的 Safari 伪装成 Firefox，或者伪装成 iPhone 上的移动版 Safari，这一方法对于网页开发者尤其适用，比如在部署移动版本的时候，就可以直接在电脑上检测网页在移动设备上的显示是否正常。

修改 Mac 版 Safari 的 User-Agent

PC 和 Mac 上的每个浏览器都有各自伪装 User-Agent 的方法，要说最简单的还真就得属 Safari 浏览器了，这里我们首先以 Mac 版的 Safari 为例说一下方法（Windows 版 Safari 也类似）：

  1. 启动 Safari 浏览器；
  2. 进入 Safari 偏好设置（可以按快捷键 command+,或者从菜单中进入）；
  3. 在偏好设置中，点击“高级”选项卡；
  4. 勾选『在菜单栏显示“开发”菜单』前面的复选框；

经过上面的操作之后，你就可以看到菜单栏多出了一个“开发”菜单，点击“开发”菜单——用户代理，直接选择你想要伪装的浏览器就可以了，如果这个列表中的都不符合您要求的话，直接选择“其他”，然后填上你想要伪装的 User-Agent 字符串即可。

修改 Mac 版 Chrome 的 User-Agent

想要修改 Mac 版 Chrome 的 User-Agent 字符串必须要在终端中完成，方法也非常简单，启动终端（应用程序——实用工具），然后运行命令：

open -a /Applications/Google\ Chrome.app/ --args --user-agent="USER-AGENT-STRING"

上面命令中的 USER-AGENT-STRING 请自行替换成你想要的 User-Agent 字符串，各个浏览器/各个版本的 User-Agent 字符串可以去 useragentstring.com 查询，Google 一下也能找到。

修改 Mac 版 Firefox 的 User-Agent

在 Mac 版 Firefox 中修改浏览器的 User-Agent 也很简单，步骤如下：

  1. 从地址栏中输入 about:config 进入 Firefox 的高级配置页面；
  2. 点击右键，新建一个字符串；
  3. 在字符串“首选项名称”框中输入 general.useragent.override；
  4. 在“字符串的值”中输入你想要的 User-Agent 字符串。

修改 Mac 版 Opera 的 User-Agent

修改 Mac 版 Opera 的 User-Agent 字符串和前面 Firefox 的操作有点类似，方法如下：

  1. 从地址栏中进入 opera:config;
  2. 在“首选项编辑器”页面中找到 User Agent(也可以直接在搜索框中搜索)
  3. 展开 User Agent 列表项之后，直接在 Spoof UserAgent ID 中填写想要的 User Agent 字符串值就可以了。

这个教程基本上覆盖了 Mac 平台几大主流浏览器了，有需要的朋友记得收藏这个网页，以后就不用再到处搜了。
