|I believe this is an issue with Xcode’s new interface builder. Did you happen to build your .xib using Xcode 4.5’s interface builder? I’ve run into this same problem just now, and I think that’s the problem. My app runs on iOS 6, but not anything older.

And you need to make sure you turn off “use auto layout” for your nibs.

That can be done by

In the main view of your xib, under File Inspector tab, in Interface builder Document section on the right toolbar. There is a checkmark “Use AutoLayout”

I had the same problem when I downloaded new XCode update and IOS6 SDK.

Select the Interface builder file (whether xib or storyboard file) where your error occurs. In assistent editor on rightmost in XCode, select the first tab from the left, and there must be checkbox for option “Use Autolayout” like on the screenshot above. Uncheck the checkbox.

That solved the problem in my case.

Best regards.
